# StudyGen AI – Smart Study Generator Agent

## Overview
StudyGen AI is an AI-powered educational assistant developed using IBM watsonx Orchestrate. It helps students understand concepts, generate quizzes, summarize notes, create flashcards, and build personalized study plans.

## Technologies Used
- IBM watsonx Orchestrate
- IBM Granite Models
- IBM Cloud
- HTML5
- CSS3
- JavaScript

## Features
- Concept Explanation
- Smart Summaries
- Quiz Generator
- Flashcards
- Personalized Study Planner
- Exam Preparation
